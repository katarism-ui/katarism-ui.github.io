개인정보처리방침

최종 갱신일: 2026년 9월 22일

Strategy Lab Sync(이하 "본 앱")는 개발자 본인이 사용하는 단일 사용자용 도구입니다. 본 방침은 본 앱이 Google 계정 데이터를 어떻게 취급하는지 설명합니다.

1. 수집하는 정보

본 앱은 Google OAuth 2.0을 통해 다음 범위의 접근 권한을 요청합니다.

https://www.googleapis.com/auth/drive — Google Drive 내 파일 및 폴더의 조회, 생성, 수정, 삭제 권한.

본 앱은 이름, 프로필 사진, 연락처, 이메일 본문, 캘린더 등 Drive 외의 어떠한 Google 사용자 데이터도 요청하거나 수집하지 않습니다.

2. 정보의 사용 목적

취득한 접근 권한은 사용자가 지정한 동기화 대상 폴더의 파일 목록을 비교하고, 변경된 파일을 업로드 또는 다운로드하는 용도로만 사용됩니다. 파일 내용은 전송 과정에서만 처리되며, 내용을 해석·분류·색인하지 않습니다.

3. 정보의 보관

본 앱은 서버를 운영하지 않습니다. OAuth 액세스 토큰 및 갱신 토큰은 사용자의 로컬 기기와 사용자가 직접 관리하는 개인 서버의 설정 파일(rclone.conf)에만 저장되며, 개발자가 통제하는 외부 저장소로 전송되지 않습니다. 파일 데이터는 동기화 대상 기기의 로컬 디스크에 보관됩니다.

4. 정보의 공유 및 제3자 제공

본 앱은 Google 사용자 데이터를 어떠한 제3자와도 공유, 판매, 양도하지 않습니다. 광고, 광고 타게팅, 신용 평가, 인적 검토 목적으로 사용하지 않으며, 인공지능 또는 기계학습 모델의 학습에 사용하지 않습니다. 본 앱의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 준수합니다.

5. 데이터 보안

Google API와의 모든 통신은 HTTPS로 암호화됩니다. 자격증명 파일은 소유자 전용 권한(0600)으로 보관되며, 서버 접근은 SSH 키 인증으로 제한됩니다.

6. 데이터 보존 및 삭제

사용자는 Google 계정 권한 페이지에서 본 앱의 접근 권한을 언제든 철회할 수 있습니다. 철회 시 저장된 토큰은 즉시 무효화됩니다. 로컬에 남은 설정 파일과 동기화된 파일은 사용자가 직접 삭제할 수 있습니다.

7. 아동의 개인정보

본 앱은 13세 미만 아동을 대상으로 하지 않으며, 해당 연령대의 개인정보를 의도적으로 수집하지 않습니다.

8. 방침의 변경

본 방침이 변경될 경우 이 페이지에 갱신된 내용과 최종 갱신일을 게시합니다.
